# TASK-23 — Employee History Search And Filter

## Goal
Employee profiles with longer histories should be easy to scan without leaving the profile.

## Scope
- Add client-side search to an employee's History section.
- Add quick filters for follow-up, resolved, high-attention, conversations, and notes.
- Keep note/transcript links and Advisor chat actions available after filtering.
- Preserve the empty-history state.

## Acceptance
- Employee history can be searched by text, type, or status.
- Filter counts show the visible/total history records.
- Filtering to zero records shows a clear empty result message.
- Existing document and advisor-chat actions still work for visible records.
