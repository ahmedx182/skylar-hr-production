# TASK-8: High-Risk Note Detection And Hold-To-Escalate

## Goal
When a saved employee note contains high-risk HR language, Skylar should flag it clearly and give the manager a deliberate path to send it to the advisor queue.

## Scope
- Detect high-risk note language during note create/update.
- Mark detected notes as red/high attention in the ledger.
- Show an escalation action on high-risk daily briefing cards.
- Require press-and-hold before creating an advisor case.
- Create a real advisor queue item from the ledger entry.
